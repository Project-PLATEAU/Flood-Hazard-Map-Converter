# 3 インストール手順
## 3-1 Python をインストールする

本システムを実行するには Python が必要です。公式サイト（[https://www.python.org/downloads/](https://www.python.org/downloads/)）から適切なバージョンの Python をダウンロードし、インストールしてください。

### インストール時のポイント
- 「Add Python to PATH」にチェックを入れる（Windows の場合）
- インストール完了後、以下のコマンドで Python が正しくインストールされているか確認してください。

```sh
python --version
```

または

```sh
python3 --version
```

バージョンが表示されれば、インストールは成功です。

## 3-2 必要なライブラリをインストールする

本システムが必要とするライブラリを `requirements.txt` を使用してインストールしてください。

###  コマンドを入力する場所
- **Windows の場合**: `Win + R` → `cmd` と入力 → Enter
- **Mac の場合**: `Command + Space` → 「ターミナル」と検索
- **Linux の場合**: `Ctrl + Alt + T`

### インストールコマンド
```sh
python -m pip install -r requirements.txt
```

`requirements.txt` の内容:
```
pandas==2.2.2
geopandas==1.0.1
shapely==2.0.5
```

 **Windows で `pip` コマンドが認識されない場合の対処法**

```sh
python -m ensurepip --default-pip
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```


## 3-3 ジオイド・モデルのダウンロード

本システムでは、国土地理院のジオイド高を変換するためのジオイド・モデルが必要です。

###  ダウンロード手順
1. [国土地理院のダウンロードページ](https://fgd.gsi.go.jp/download/geoid.php) にアクセス
2. **「ASCII 形式のデータ」** から `gsigeo2011_ver2_2_asc.zip` をダウンロード
3. ダウンロードした `gsigeo2011_ver2_2_asc.zip` を **プログラムと同じフォルダ** に格納
4. `gsigeo2011_ver2_2_asc.zip` を解凍し、以下のファイルがあることを確認

```
gsigeo2011_ver2_2.asc
```
